# Ai-jarvis
An Assistant 
🤖 AI-Assistant – Self Hosted Personal AI (WSL + Ollama)
A fully offline, local, and intelligent AI Assistant built using CodeLlama, Ollama, Flask, and Vector Database (FAISS)
🚀 Project Overview

This project implements a personal AI assistant that runs completely on your own machine using:

Self-hosted Large Language Model (LLM)

Conversational chatbot UI

Knowledge storage and retrieval

Retrieval-Augmented Generation (RAG)

No internet dependency

It works as your own private version of ChatGPT / Jarvis for local use.

🧠 Features

✔ Self-hosted AI using CodeLlama via Ollama
✔ Modern Web Chat Interface
✔ Context-aware responses
✔ Knowledge storage (long-term memory)
✔ Vector Database using FAISS
✔ Retrieval Augmented Generation
✔ Fully Offline – No cloud required
✔ Runs completely inside WSL
